# Adaptador MongoDB (pendiente)

Implementar repositorios de resultados de escáner y evidencias técnicas según
database/mongodb/README.md y collections.schema.json. Sin importación de datos
demo, creación de colecciones ni conexión automática en esta entrega.

Antes de escribir: verificar en PostgreSQL que el diagnóstico existe y que el
actor puede acceder a él. MongoDB no reemplaza diagnósticos.resumen ni registra
pagos, clientes o credenciales. Las referencias SQL no son claves foráneas MongoDB.
