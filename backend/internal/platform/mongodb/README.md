# Adaptador MongoDB implementado

Driver oficial Go v2; validadores BSON embebidos en `validators.json`, índices, documentos de escáner y metadatos/GridFS. La autorización y existencia del diagnóstico se comprueban en PostgreSQL antes del acceso técnico.

El contrato vigente y el procedimiento explícito de inicialización se describen en [database/mongodb/README.md](../../../../database/mongodb/README.md). No importar datos demo ni duplicar registros transaccionales. Las pruebas de integración utilizan únicamente instancias temporales nuevas.
